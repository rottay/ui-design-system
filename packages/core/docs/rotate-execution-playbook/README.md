# Rotate Execution Playbook

## Purpose

This folder converts the quality reset audit into an execution-ready package for Claude.

It is not another broad critique. It is the implementation brief for getting
Rotate from "functional but under-authored" to a truthful premium flagship.

## Baseline

- visible Rotate / Modern quality baseline: `~5.2/10`
- shell / layout ownership: `~4.4/10`
- dashboard control room quality: `~4.6/10`
- user workspace / data UX: `~5.4/10`
- guardrails / truthfulness: `~5.4/10`
- cross-app coherence: `~4.9/10`

## Key Truth

The main problem is not missing token surface alone.

The main problem is a compound of:

- weak authored visual direction
- shell ownership still living in `app-platform`
- dashboard and workspace composition that overpacks information without enough hierarchy
- hybrid bundled-vs-DB tenant model at the app boundary
- admin authoring still centered on legacy branding blobs instead of the DS contract
- guardrails that prove plumbing more than product quality
