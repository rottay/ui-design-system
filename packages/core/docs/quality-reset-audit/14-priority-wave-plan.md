# Priority Wave Plan

## Priority 0 - Visual Direction Reset

Goal:
Define a stronger authored visual grammar for Rotate before more token work.

Must-do:
- redesign shell hierarchy
- redesign dashboard hero/control room composition
- reduce ambient grid/gloss usage
- establish stronger typography and contrast rules

## Priority 1 - Shell Ownership Consolidation

Goal:
Move more visible shell logic from `app-platform` into DS-owned structures.

Must-do:
- centralize shell geometry
- promote stronger header/topbar patterns
- reduce host-local gradients and spacing recipes

## Priority 2 - Data Workspace Quality

Goal:
Turn the table/workspace experience into a premium operational surface.

Must-do:
- keyboard-accessible sorting and row activation
- stronger row/header hierarchy
- more comfortable search/filter chrome
- clearer framing of table workspaces

## Priority 3 - Tenant Model Completion

Goal:
Close the gap between bundled and DB tenant stories.

Must-do:
- move admin authoring toward `appearance.general`
- extend DB adapter to the bounded v1 contract
- reduce legacy branding dependence

## Priority 4 - Primitive Authoring Pass

Goal:
Upgrade the visible Modern surfaces still reading as generic.

Must-do:
- Card
- Menu
- CollectionHeader
- SearchCommandBar
- Statistic

## Priority 5 - Guardrails

Goal:
Make generic mediocrity harder to reintroduce.

Must-do:
- add visual-quality rubric checks
- add accessibility checks for data tables
- add host-vs-DS shell ownership tracking
