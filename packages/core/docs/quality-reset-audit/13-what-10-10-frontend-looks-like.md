# What A 10/10 Modern Frontend Should Look Like

This is the target standard, not the current state.

## Layout

- one clear layout grammar
- obvious focal regions
- stronger differences between overview, workspace, and control room
- fewer containers with more intentional structure

## Hierarchy

- headlines that establish dominance quickly
- supporting copy that is brief and useful
- metrics and actions ranked visibly
- calm regions for reading and decisive regions for acting

## Branding

- one unmistakable visual move
- typography that feels selected, not inherited
- color used as a control signal, not decoration
- product chrome that communicates identity instantly

## Data UX

- tables that scan fast
- controls that feel comfortable
- keyboard parity for critical operations
- dense data with real editorial rhythm

## Motion

- motion that supports state change and orientation
- no decorative churn
- clear open/close/focus hierarchy

## Customization

- tokens do not just recolor the same design
- tenants can create different product character
- runtime authoring is bounded but real
- bundled products feel fully authored

## Honesty

- docs, contracts, runtime, tests, and visible UI tell the same story
