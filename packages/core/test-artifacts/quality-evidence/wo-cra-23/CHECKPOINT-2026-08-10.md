# Checkpoint — 2026-08-10

The single operative document. It replaces iterating on the fly: what is true, what is broken,
what to do, in what order, and how each claim was established.

## How to read every claim here

Three states are NOT the same thing, and conflating them was the failure mode across this whole
tree. Every claim is tagged:

| Tag | Means |
|---|---|
| **[V]** | VERIFIED HERE — re-derived mechanically in this session; command or file:line given |
| **[L]** | LANE-REPORTED — an audit lane established it; method stated; not independently re-run |
| **[C]** | CLAIMED BY AN ARTIFACT — a doc/ledger/registry asserts it; a hypothesis, not a fact |

For every rule also distinguish **WRITTEN DOWN** vs **ENFORCED BY A MECHANISM** vs **CURRENTLY
RUNNING**. Most governance here is only the first. Reading a **[C]** as a **[V]** produced at least
four separate defects this session.

## 1. The three root causes

Everything below reduces to these. They are independent and must be fixed in this order.

### RC1 — Every instrument measures REACHABILITY. None measures RESOLUTION.

Reachability asks *does a chain connect?* Resolution asks *what does the browser paint?*
Three lines converged: the synchrony census (*"topological… never what it resolves to"*), the
published impact map's own legend (*"scope/cascade are not modelled"* **[V]**), and the radius
defect, which lives exactly in that gap.

**Consequence:** wiring validated only by reachability can move a number without moving a pixel.
This programme has already done that and reverted it twice.

### RC2 — The canon has the right shape and a DEAD FLOOR. **[L]**

The layered chain `component → material → canon` is real and uniform — it recurs 460× for border,
684× for surface, 202× for depth. But the middle names are **declared**, so the canonical fallback
is inert (`var(--a, --b)` never reaches `--b` when `--a` is declared in scope).

| concept | chains ending in canon | canon UNREACHABLE in base bundle |
|---|---:|---:|
| Surface | 616 | **463 (75%)** |
| Border | 463 | **305 (66%)** |
| Depth | 163 | 94 (58%) |
| Radius | 258 | 149 (58%) |

Traced end-to-end: `input.css:55` paints
`var(--ds-input-border, var(--ds-material-control-border, var(--ds-color-border)))`.
`--ds-input-border` **is** declared, so both fallbacks are dead and `--ds-color-border` can never
fire. That is why a tenant's border decision does not reach the Input.

**This is not the compiler fanning out one tenant decision.** The deciding value is hand-authored
inside the DS (border 270, surface 319 sites) far more often than compiler-emitted (70, 71),
concentrated in `themes/default.css`, `patterns.css`, `button.css`, `input.css`, `card.css`.

**The fix is DELETION, not authoring** — see W2.1.

### RC3 — Nothing prevents a duplicate token. The anti-duplication step is a person. **[L]**

> Mint `--ds-card-edge-hairline` today alongside the existing border role, run
> `pnpm tokens:catalog:write`, and **all 52 blocking gates pass.**

The repo can prove a token is REGISTERED, OWNED, CLASSIFIED, DOCUMENTED and CONSUMED. It cannot
prove a token is **NOT A DUPLICATE**. What people cite and what it actually is:

- `tokens-catalog.mjs:1163-1173` "two-authorities heuristic" — a **hardcoded three-entry list**
  (`--ds-text-`, `--ds-border-color-`, `--ds-density-spacing-`). It detects only the three duplicate
  families a human already found. No similarity computation exists anywhere.
- `:1154-1161` "no capability id in two tiers" — an **id** collision, not a **concept** collision.
- `tokens-catalog --check` failing on "name missing from family pages" is a **freshness** gate:
  regeneration auto-files a new name into its prefix-derived page and the failure disappears.
- `rounds.json` R5 exit `"public tokens created by visual lanes equals 0"` — **[WRITTEN] only.**
  Nothing computes it.

**Everything downstream of the judgement is mechanised; the judgement itself has no executable
form, and its designated judge is not installed.**

## 5. Edge cases and traps

Every one of these drew blood. They are the difference between an autonomous worker producing
evidence and producing confident nonsense.

### 5.1 Measurement traps

| Trap | Consequence | Defence |
|---|---|---|
| `cmd \| tail` then `$?` | reads `tail`'s exit. Reported 3 gates green that were red | capture exit directly |
| `grep -- "x" DIR --include=…` | `--` ends option parsing; `--include` becomes a PATH and filters nothing | put `--include` before `-e` |
| `rg -rn` | `-r` is `--replace`; correct shape, corrupted payload | never `-r` unless replacing |
| Double-quoted attribute sweeps | this repo's CSS uses **single** quotes — false ZERO | be quote-agnostic |
| Summing specificity across a comma list | inflates a selector; would have reported the runtime LOSING | max per selector, with self-tests pinning each rung |
| `vars[CONSTANT_NAME] = …` | a literal-only emitter scan reports a live dial as dead | resolve constants |
| A gate with a wrong corpus path | scans nothing, passes everything (3× in one day) | every gate asserts a floor on its own corpus |
| A count without scope | the 845 excludes all CSS; every "zero readers" here is **DS-internal** | state what was scanned AND excluded |
| Interpolated names | **217 prod sites** (307 with tests) invisible to every scan. The bulk is `--ds-color-${role}-${step}`, `--ds-material-${role}-*`, `--ds-surface-${role}` — NOT `--ds-type-${…}`, which is only 11 sites | spell names literally in a channel table |
| **A generated block read only by interpolation** | the ~294-name material/type blocks and the 100-name `--ds-color-{role}-{step}` grid are reached ONLY through interpolation, so **every read count in this repo is a floor understated by up to ~300 names** | never conclude "unused" from a read count alone |
| Measuring source shapes in `dist` | a bundle emits `(0, mod.fn)(…)` — `fn(` returns zero | never |

### 5.2 The dead-list trap — do not delete on "zero readers"

The literal census **self-flagged its own 378-entry dead list as UNUSABLE**: 377 of 378 are matchable
by an interpolated read shape. Worse, reader counts here are **DS-scoped**: `--ds-text-eyebrow` reads
dead inside the DS and has **4 live app-bithire readers**.

**Rule: retirement requires DEATH-PROOF — positive evidence the reader was deliberately struck —
and an APP-SCOPE re-count. Never the absence of a static match.** Applies to
`--ds-chart-series-*` and to the 11 `tall-card-*` channels (task #12).

### 5.3 Build and gate traps

- `pretest` (→ the 52 gates) fires **only** for the script literally named `test`. `test:run` and
  `test:unit` skip it. Never run bare `… run test` — watch mode *and* the full gate cost.
- `build` runs `build:vertical-css`, regenerating every artifact **in place** — committed drift
  disappears before any test sees it. **Staleness checks run BEFORE build.**
- Several gates read `dist/`; a stale `dist` makes the gate measure the previous build (§3.2).
- Visual regression needs a **production** showroom build; dev paints non-deterministically. The
  showroom renders `packages/core/dist`, not `src`.
- Kill stale :7001 by hand — `reuseExistingServer` silently attaches and poisons pixels.
  `pnpm next:free` does **not** free 7001.

### 5.4 CSS correctness traps

- **Fallback-inert law**: `var(--a, --b)` never reaches `--b` if `--a` is declared anywhere in scope.
  This is RC2 and it is the most common silent defect here.
- **Specificity beats order**: an artifact block at (0,1,1) always beats `:root` (0,1,0); the runtime
  tenant block at (0,4,0) beats every artifact block (§2.5).
- A state channel must not resolve to the element's resting value.
- "Declares nothing" ≠ "renders nothing" — compare COMPUTED values.
- **Invalid `color-mix()` neither throws nor fails a snapshot** — it silently drops the declaration.
- **oklch interpolates hue as an ANGLE** — a chromatic ground drags a tone across the wheel (this
  produced rottay's green-grey `#CCDCCA` where the brand says blue).

### 5.5 Multi-agent traps

- **A subagent's plain text is INVISIBLE to the lead.** Only `SendMessage` arrives. **Three lanes
  reported into the void today.** Every delegation prompt must say so explicitly.
- Scratchpad filenames are keyed by SESSION, not agent — prefix with the work-order id.
- One shared tree: only the coordinator commits, with explicit pathspecs. Never `git add -A`; never
  `git commit -- <path>` (bypasses the index).
- Attribute a shared-tree gate failure by **re-running in a clean worktree**, never by reading a diff.
- Build/test/browser are **singletons**. Writers never run them.
