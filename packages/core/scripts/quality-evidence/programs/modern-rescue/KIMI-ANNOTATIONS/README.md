# Kimi annotations — temporary advisory inbox

This directory is a disposable review boundary, not a roadmap, evidence
archive, implementation lane or token authority. The Modern-rescue contracts
in the parent directory are the sole program canon.

Kimi may add new files only under `inbox/` for the currently authorized audit.
Kimi must not edit existing files here or anywhere else in the repository.
Codex independently verifies every useful observation, incorporates accepted
changes into the owning canonical contract and then deletes the raw submission.
Rejected, duplicated and superseded observations are not retained.

Claude never reads or implements raw Kimi output. Claude receives only the
reconciled parent program and its canonical bootstrap prompt.

There is no active Kimi audit after the final program reconciliation. If the
owner authorizes another advisory in the future, Codex derives a fresh prompt
from the then-current canon; no previous prompt or submission is reused.

Allowed proposal result vocabulary:

- `REUSE_EXISTING_CANON`
- `COMPOSE_EXISTING_AXES`
- `PRIVATE_FAMILY_PROPOSAL`
- `RECIPE_OR_PROFILE_CANDIDATE`
- `STANDARD_OR_PRO_CANDIDATE`
- `EXPERT_CANDIDATE`
- `APP_LAYER_SUGGESTION`
- `REJECT_AS_DUPLICATE_OR_DECORATIVE`

These are temporary recommendations only. They do not promote tokens, approve
work or become historical documentation.
