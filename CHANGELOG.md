# Changelog

All notable changes to this repository are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the
package follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

This file covers the repository. The published package keeps its own release history,
generated by the release flow, at `packages/core/CHANGELOG.md`. See
[docs/releasing.md](docs/releasing.md) for how a change becomes a version.

## Unreleased

### Pending major — 3.0.0

A major release is staged but not yet published. Its full breaking-change list is the
release intent at
[`.changeset/major-canonical-tree.md`](.changeset/major-canonical-tree.md), which is the
authority; the summary here is orientation only and is finalized at publish time.

The release consolidates the design system onto its target architecture — one capability,
one owner, one public name — and accumulates the public-API removals that accompany it.
Two consequences matter to a consumer:

- **Subpaths are removed**, and the capabilities behind them are consumed from the root
  barrel under their reclassified names.
- **Upgrade codemods will ship with the release** to automate the import migrations. They
  are not available yet.

Read the changeset before planning an upgrade.

### Added
