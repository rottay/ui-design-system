## Patterns and Insights

### When We Win

1. **Fast POC Completion** - Deals where POC completed in < 2 weeks have 3x higher close rate
2. **CTO/Engineering Leadership Involved** - Technical decision makers respond well to our developer experience
3. **Multi-Tenant Requirements** - B2B SaaS companies building for multiple customers
4. **Compliance-Sensitive Industries** - Fintech, healthcare, enterprise software
5. **Integration Complexity Concerns** - Customers worried about auth integration timelines

### When We Lose

1. **Existing Vendor Relationship** - Customer already has Auth0/Okta deployed and switching cost is high
2. **Workforce Identity Needs** - Requirement for employee SSO, directory sync
3. **AWS Ecosystem Lock-In** - Heavy AWS shops prefer Cognito for billing simplicity
4. **Brand Recognition** - Enterprise security teams prefer known vendors
5. **Simpler Use Cases** - B2C apps with basic auth needs, free tier sufficient elsewhere
