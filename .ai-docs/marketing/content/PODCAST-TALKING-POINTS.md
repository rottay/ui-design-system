# Podcast Talking Points

Ready-to-use talking points for podcast appearances.

## The Founding Story
- "We built the same auth, tenancy, compliance code 3 times for different startups"
- "Realized every B2B SaaS rebuilds the same 500K lines of infrastructure"
- "So we built it once, properly, and made it a platform"

## The Problem We Solve
- "Average B2B SaaS integrates 6-10 infrastructure vendors"
- "That's 6 SDKs, 6 invoices, 6 support queues, 6 security surfaces"
- "Integration time: 3-6 months before you write your first feature"

## The Aha Moments
- "When we realized multi-tenancy could be one parameter: { tenantId }"
- "When we counted and found we'd written 1,000+ use cases"
- "When a customer said 'this would have saved us a year'"

## Technical Differentiators (For Technical Podcasts)
- "Every use case returns Result<T> - no exceptions in business logic"
- "RBAC is a decorator, not an integration"
- "Tenant isolation is architectural, not middleware"

## Business Differentiators (For Business Podcasts)
- "$27,880/year is what you pay for basic infrastructure vendors"
- "We consolidate that into one platform, one invoice"
- "Enterprise features from day one, not day 365"

## Competitor Soundbites
- "Auth0 solves authentication. We solve the whole infrastructure layer."
- "Vanta tracks compliance. We implement it."
- "LaunchDarkly charges per seat. We include feature flags."

## Q&A Prep

### "How do you compete with Auth0?"
Answer: "We don't compete with Auth0. We replace Auth0 plus 5 other vendors..."

### "Isn't this too much for one platform?"
Answer: "Is authentication too much? Is compliance? They're all table stakes for B2B SaaS..."

### "What about vendor lock-in?"
Answer: "We use standard patterns - PostgreSQL, TypeScript, REST. Compare that to proprietary query languages..."
