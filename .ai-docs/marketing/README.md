### Competidores Principales
| Categoria | Competidores |
|-----------|--------------|
| Auth | Auth0, Clerk, Firebase Auth, Cognito, Supabase |
| Compliance | Vanta, Drata, Secureframe |
| Feature Flags | LaunchDarkly, Split, Statsig |
| Permissions | Permit.io, Oso, Cerbos |
| Multi-tenancy | Nile, Turso |
| Notifications | Twilio, SendGrid, Knock |

### Datos de Ataque
- **Auth0:** 4 outages en 2024, 34% citan pricing como problema
- **Vanta:** Solo 5 frameworks (vs 15 de Rottay), audit fees separados
- **Azure AD B2C:** Sunset Mayo 2025 (URGENTE)
- **Firebase Auth:** SMS costs ocultos ($6K/mes a 100K verificaciones)
- **LaunchDarkly:** Per-seat pricing escala mal
- **AWS Cognito:** Aumento 3x en Diciembre 2025

### TCO Comparison
- **Stack tradicional (6 vendors):** $27,880/year + 8-12 semanas integracion
- **Rottay:** Una plataforma, 1-2 semanas integracion
