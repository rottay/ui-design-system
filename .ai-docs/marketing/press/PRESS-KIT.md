## Story Angles

### The Origin Story
"We built the same infrastructure 3 times at 3 different startups. 500,000 lines of code every B2B SaaS needs. So we productized it."

**Details:** The founding team spent years building enterprise software, watching the same patterns repeat: months spent on authentication, permissions, compliance tracking. Each time, the same 6 months of work before a single feature could be built. Rottay was born from the realization that this infrastructure layer should be a product, not a project.

### The Market Problem
"Average B2B SaaS uses 6-10 infrastructure vendors. That's $30K+/year and 3-6 months of integration before writing a single feature."

**Details:** Today's B2B SaaS company typically relies on:
- Auth0 or Clerk for authentication ($4,200-$10,560/year)
- Vanta or Drata for compliance ($9,000-$15,000/year)
- LaunchDarkly for feature flags ($4,000-$9,600/year)
- Multiple other point solutions

Each vendor means another SDK to learn, another security surface to monitor, another integration to maintain.

### The Technical Innovation
"Every use case returns Result<T> - no exceptions in business logic. Multi-tenancy in one parameter. 15 compliance frameworks implemented, not just tracked."

**Details:** Rottay's architecture represents a different approach to infrastructure:
- Functional Result types replace try-catch chaos
- Every operation is tenant-aware by default
- Compliance controls are built into the code, not just tracked in a dashboard
- Domain-driven design with 17 bounded contexts

### The Competitive Angle
"Auth0 had 4 outages in 2024. Vanta only covers 5 frameworks. LaunchDarkly charges per seat. We built everything, better."

**Details:** The incumbent vendors have become complacent:
- Auth0: 34% of customers cite pricing as main pain point, frequent outages
- Vanta: Tracks compliance but doesn't implement controls
- LaunchDarkly: Per-seat pricing makes scaling expensive
- All: Focus on one problem, forcing customers to integrate multiple tools

### The Migration Opportunity
"Azure AD B2C is being sunset in May 2025. AWS Cognito is raising prices 3x. The market is ready for a new approach."

**Details:** The next 12 months represent a unique opportunity:
- Microsoft deprecating Azure AD B2C (May 2025) - millions of apps need new auth
- AWS Cognito pricing increase (December 2025) - 3x cost jump
- Growing frustration with vendor sprawl and integration complexity
