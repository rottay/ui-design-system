## Is It Safe?

**YES. Very safe.**

Rottay follows the same security rules as:
- Banks (where your money is)
- Hospitals (where your health records are)
- Government agencies

All data is "encrypted" - which means it's scrambled so only the right people can read it.

### Like a locked safe:

- Even if someone breaks into the building, they can't open the safe
- Only people with the key can see what's inside

### We have official certifications that prove our security:

- **SOC2** (the security standard for tech companies)
- **HIPAA** (the security standard for health data)
- **GDPR** (the European privacy law)
