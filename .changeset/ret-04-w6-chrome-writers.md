Internal restructure: the chrome CSS variable emitter (`infrastructure/compilers/kernel/foundation/css/chrome-variables`) moves seven template-free writers (`setMappedChromeVars`, `setLegacyDangerButtonAlias`, `setCardBandVars`, `setListingGridVars`, `setListVars`, `setDetailVars`, `setSurfaceChromeVars`) into an internal `writers` module, and the existing path stays the emitter entry point. The writers are reachable only from that entry point; no package subpath is added. The five interpolating writers, `setBadgeChromeVars` and every call site stay in the entry point. `chromeToVariables`, `sidebarToneToVariables`, `PRODUCER_RANK`, `FROZEN_ENGINE_COMPAT_CHANNELS` and every other export keep their declarations, and the emitted variable names, values and insertion order are unchanged. The closed emitter authority gains a writer member that must hold only template-free writers, import types only, name them in one trailing export list and be imported by the entry point, and a data table may now reference only an earlier table of the same member. The integration audit scans every member the entry point imports. The published package API does not change.
