Internal tooling only: the channel-producer census resolves a template hole across the chrome CSS variable emitter, from a template in its writer member to the literal call sites in its entry point, when the entry point is the writer member's only importer. The emitter authority gains that privacy law, admits a template channel key in a writer only as `vars[`…`] = value` (or through a local key-prefix const) whose holes are the writer's parameters, refuses any other reference to a writer by name inside the writer member, and requires the entry point to import its writers without aliases. Tenant reach declares, per interpolating emitter, the file that holds its call sites and the file that defines it. The census, reach set and every gate output are unchanged on the current tree; no shipped file changes and the published package API does not change.
