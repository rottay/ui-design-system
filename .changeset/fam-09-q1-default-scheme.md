WO-FAM-09 Q1 (owner resolution R3). The `default` chart scheme no longer
paints the `accessible` table: it resolves its own governed 12-slot chain
(teal/ochre/terracotta hue lanes + a warm neutral anchor, slots 11/12 derived
by the same OKLab rule as every scheme). This is a deliberate visual change:
default-scheme charts repaint in every vertical. `accessible` is unchanged and
remains an explicit supported scheme; every scheme clears the 3:1 floor in
both modes (default minimum 4.26:1 light / 5.88:1 dark). No API changed.
