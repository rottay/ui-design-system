**5. B5 — the original decoy is rejected, but attachment plus zero-count closure still permits a false green.**

The new D9 rule correctly rejects the original `void unusedTransport.session` decoy. The separate zero-independent-implementations condition is also necessary.

However, [the attachment predicate](/Users/daniel/Developer/Rottay/r4-recon-opus/evidence/dnd-kernel-debrief/index.md:2534) counts a JSX spread without checking whether later props overwrite its handlers. Meanwhile, [the drop-zone count](/Users/daniel/Developer/Rottay/r4-recon-opus/evidence/dnd-kernel-debrief/index.md:2518) requires independent hover state, excluding stateless independent file-drop handling.

This counterexample compiles under strict TS 5.9.3:

```tsx
const zone = useFileDropZone({ onFiles: () => {} });

return (
  <div
    {...zone.dropZoneProps}
    onDragOver={event => event.preventDefault()}
    onDragLeave={() => {}}
    onDrop={event => {
      event.preventDefault();
      onUpload(Array.from(event.dataTransfer.files));
    }}
  />
);
```

Executing the transpiled JSX confirms that the independent handler wins:

```text
Kernel handler calls:       0
Independent upload calls:  1
```

Applying the **specified predicates**, rather than claiming to run the unimplemented gate:

```text
dndKernelWired       = true   // JSX spread exists
dndTransportOwners  = 0      // no sortable session
dndDropZoneOwners   = 0      // no independent hover state
blocking finding    = false
zero-count closure  = true
```

The kernel is bypassed, yet the proposed consolidation proof passes.

D11 has a related limitation: passing a bag to a child is not evidence that the child consumes it. Also, the closure paragraph still says the original decoy is wired, contradicting D9’s explicit `false`.

**Required correction:** measure effective handler attachment, reject overwritten or unconsumed bags, and prevent unclassified independent drop handlers from disappearing merely because they lack hover state. Add the overwrite counterexample to the drill.
